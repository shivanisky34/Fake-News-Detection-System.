# Fake News Detection System

A deep Learning project built using Python and Natural Language Processing (NLP) technique (TF-IDF) to detect and classify news content as **Real** or **Fake**.

## 📌 Features
- Text Preprocessing using NLP
- Feature Extraction with TF-IDF Vectorizer
- Classification using PassiveAggressiveClassifier / Logistic Regression
- Evaluation metrics: Accuracy Score, Confusion Matrix, Classification Report

## 🛠️ Tech Stack & Requirements
- **Python 3.x**
- `pandas` - Data manipulation
- `numpy` - Numerical operations
- `scikit-learn` - Machine Learning & NLP vectorization
